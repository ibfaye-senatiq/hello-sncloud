# hello-sncloud

Minimal Next.js 14 reference workload for **SN Cloud**. Deployed via the Coolify
API (public-repo path) to prove the `GitHub repo → build → HTTPS URL` pipeline.

This is a **test/reference app only** — it contains no secrets and no real
logic. The real reference workloads (`mbour2035`, `mbour-digital-hub`) will be
deployed once their repos exist.
